\chapter*{Changelog}
\addcontentsline{toc}{chapter}{Changelog}

This section summarizes notable changes to the textbook, code listings, and hardware testbenches since the release of the First Edition PDF (\texttt{Structured\_Computer\_Architecture\_1st\_edition\_2026\_06\_03.pdf}, June 3, 2026).

\begin{itemize}
    \item \textbf{Performance Optimized Architecture: Domain-Specific Architectures and Accelerators (Chapter 18)}: Authored a comprehensive new chapter (\texttt{Latex/04\_18\_Performance\_Optimized\_Architecture.tex}) exploring architectural paradigm shifts beyond the ILP wall, organized around Domain-Specific Architectures (DSAs) and modular RISC-V extensions:
    \begin{itemize}
        \item \textit{The Post-ILP Era and the Rise of DSAs}: Analyzed the triad of physical scaling limits (breakdown of Dennard scaling and the Power Wall, ILP Wall, and Memory Wall), dark silicon, and the prohibitive $80\text{--}90\%$ von Neumann control overhead of out-of-order general-purpose cores. Framed DSAs via Amdahl's Law and the modular RISC-V standard extensions (`F', `D', `V', `P', `Zfh', and `RV-M').
        \item \textit{HPC and Floating-Point Architecture}: Examined IEEE 754 compliance, alignment/normalization shifters, dynamic rounding modes, accrued exception flags, the RISC-V 32-register floating-point file (\texttt{f0}--\texttt{f31}) with readable/writable \texttt{f0} and NaN-boxing, \texttt{fcsr}, FMA units, and pipelined floating-point datapaths.
        \item \textit{Vector Processing and Data-Level Parallelism}: Contrasted packed-SIMD rigidity with Cray-style scalable vectors. Detailed the RISC-V Vector (RVV) extension architecture (\texttt{VLEN}, \texttt{ELEN}, \texttt{SEW}, \texttt{LMUL}), dynamic vector length calculation via \texttt{vsetvli}, stripmining loops with assembly code, multi-lane vector execution datapaths, and memory access topologies (unit-stride, strided, and indexed gather/scatter).
        \item \textit{GPUs and Massively Parallel SIMT}: Analyzed Single Instruction, Multiple Threads (SIMT) versus SIMD, warp/wavefront lockstep execution, zero-overhead multithreaded warp schedulers for memory latency hiding, branch divergence management via active masks and execution divergence stacks, and open-source RISC-V SIMT GPGPU architectures (Vortex).
        \item \textit{Digital Signal Processors (DSPs) and Embedded Compute}: Explored FIR and FFT computational kernels, fixed-point $Q$-format arithmetic with saturation and guard bits, dual-memory Harvard architectures (X/Y memories), dedicated Address Generation Units (AGUs) for circular modulo and bit-reversed addressing, and the RISC-V packed-SIMD `P' extension.
        \item \textit{Tensor and Matrix Processors for AI}: Analyzed deep learning GEMM computational kernels, arithmetic intensity and the roofline model, 2D systolic array architectures with weight-stationary dataflows (Google TPU), sub-word low-precision numerics (INT8, FP8, BF16), and the emerging RISC-V Matrix (\texttt{RV-M}) extension.
        \item \textit{Comparative Synthesis of DSAs}: Synthesized all computational paradigms in a comprehensive cross-cutting comparison table contrasting CPUs, Vectors, GPUs, DSPs, and TPUs across instruction bandwidth, control overhead, memory organization, and peak energy efficiency.
    \end{itemize}
    \item \textbf{Hardware Multithreading: Exploiting Thread-Level Parallelism (Chapter 16)}: Expanded Chapter 16 (\texttt{Latex/04\_16\_Performance\_Optimized\_Organization.tex}) with a dedicated section on hardware multithreading:
    \begin{itemize}
        \item \textit{Theoretical Foundations \& Latency Hiding}: Framed multithreading as the organizational response to the ILP Wall and Memory Wall, contrasting single-threaded horizontal and vertical issue slot waste with multithreaded slot utilization.
        \item \textit{Taxonomy of Multithreading}: Analyzed fine-grained/interleaved (barrel) multithreading (citing Burton Smith on the Denelcor HEP, 1978), coarse-grained (blocked) multithreading, and Simultaneous Multithreading (SMT) (citing Dean Tullsen, Susan Eggers, and Henry Levy, ISCA 1995).
        \item \textit{Microarchitectural Resource Partitioning}: Detailed the trade-offs between statically partitioned resources (instruction queues, reorder buffer partitions, return address stacks) and dynamically shared execution resources (physical register files, ALUs/FPUs, TLBs, and caches).
        \item \textit{Architectural Touchpoints}: Examined hardware thread identification (\texttt{mhartid} CSR), atomic memory operations (Load-Reserved/Store-Conditional and AMOs in the RISC-V `A' extension), memory fence instructions (\texttt{FENCE}, \texttt{FENCE.I}), and memory consistency models (RVWMO and TSO).
    \end{itemize}
    \item \textbf{Textbook Chapter Structure \& Downstream Renumbering}: Renumbered downstream Part IV chapters following the addition of Chapter 18:
    \begin{itemize}
        \item Renamed \texttt{Latex/04\_18\_1\_RISCV.tex} $\rightarrow$ \texttt{Latex/04\_19\_1\_RISCV.tex} (Chapter 19: The RISC-V Processor).
        \item Renamed \texttt{Latex/04\_18\_2\_RISCV\_pipelined.tex} $\rightarrow$ \texttt{Latex/04\_19\_2\_RISCV\_pipelined.tex}.
        \item Updated \texttt{Latex/00\_main.tex} inclusion sequence, aligning Chapter 20 naturally with \texttt{04\_20\_pRISC\_heterogeneous.tex}.
    \end{itemize}
    \item \textbf{Performance Optimized Organization: Pipelining and ILP (Chapter 16)}: Renamed chapter file to \texttt{04\_16\_Performance\_Optimized\_Organization.tex} and updated master inclusion in \texttt{Latex/00\_main.tex}. Enhanced chapter with rigorous pedagogical, analytical, and microarchitectural additions without disturbing existing content:
    \begin{itemize}
        \item \textit{Pedagogical Bridge \& Performance Metrics}: Added an introductory bridge connecting Chapter 15 gate-level optimizations to system-level organization and formalized the fundamental iron law of processor performance ($\text{Execution Time} = \text{IC} \times \text{CPI} \times T_{clock}$), pipeline CPI degradation, and speedup formulas.
        \item \textit{Barrel Multithreading Hazard Elimination}: Established how $N = 4$ round-robin interleaved barrel multithreading matching the $k = 4$ stage toyRISC pipeline structurally guarantees that no pipeline hazards can exist, avoiding hardware stalls and forwarding multiplexers.
        \item \textit{Structural Hazards \& Hardware Replication}: Added Section 16.3.1 analyzing structural resource contention and necessary hardware replication, from dedicated PC incrementers (+4) and Harvard memory ports in basic pipelines to multiple ALUs, AGUs, and multi-ported register files in superscalar processors, with clean subsubsection header formatting.
        \item \textit{Figure Floating \& Whitespace Elimination}: Allowed Figures 16.1, 16.2, and 16.3 to float with \texttt{[htbp]}, moved Figure 16.2 out of the middle of the 4-stage description list, and repositioned Figure 16.3 adjacent to its textual analysis to eliminate page-break gaps and excess whitespace.
        \item \textit{Forwarding Truth Table \& Priority Logic}: Added Table 16.3 and Boolean hazard expressions for ALU operand forwarding controls, formalizing the imperative priority rule when back-to-back instructions target the same destination register.
        \item \textit{Origins of Branch Prediction \& Early Pioneer Citations}: Authored Subsection 16.3.3 framing the emergence of branch prediction when instruction prefetching, pipelining, and lookahead decoupled fetch from execution. Documented the first hardware implementation in the IBM 7030 (Stretch) supercomputer \citep{buchholz1962}, crediting Richard T. Blosk's Instruction Unit \citep{blosk1960} and Richard S. Ballance, John Cocke, and Harwood G. Kolsky's Look-Ahead Unit \citep{ballance1962lookahead} for static ``predict untaken'' and speculative rollback. Documented the independent genesis of dynamic 2-bit branch prediction by Tom McWilliams and Curt Widdoes on the S-1 supercomputer at LLNL \citep{s1project1979} and James E. Smith at CDC and UW-Madison \citep{smith1983patent, smith1981study}.
        \item \textit{1-Bit vs. 2-Bit Branch Prediction Trace}: Corrected 2-bit counter description to a four-state automaton and added step-by-step trace Table 16.5 comparing 1-bit vs. 2-bit predictors on a 4-iteration loop, analytically demonstrating the elimination of the loop re-entry misprediction penalty ($(N-1)/N$ vs $(N-2)/N$).
        \item \textit{Two-Level Adaptive Branch Prediction \& Yale Patt Citations}: Added rigorous coverage of dynamic branch prediction foundations citing J.~E.~Smith \citep{smith1981study} and Lee and A.~J.~Smith \citep{lee1984branch}. Authored Section 16.3.4 subsection crediting Tse-Yu Yeh and Yale N.~Patt \citep{yeh1991twolevel, yeh1992alternative} for two-level adaptive branch prediction, Yale Patt's HPS speculative architecture \citep{patt1985hps}, the taxonomy of Global/Local History Registers (GHR/BHR) and Pattern History Tables (PHT), Scott McFarling's gshare and tournament combining predictors \citep{mcfarling1993combining}, and their deployment in modern high-performance superscalar processors.
        \item \textit{Out-of-Order Execution, ROB \& Inventor Citations}: Expanded Section 16.5 with in-depth treatments of Seymour Cray and James E. Thornton's CDC 6600 centralized Scoreboard \citep{thornton1964, thornton1970}, Robert M. Tomasulo's IBM 360/91 algorithm \citep{tomasulo1967}, and James E. Smith and Andrew R. Pleszkun's Reorder Buffer (ROB) for precise interrupts and speculative branch retirement \citep{smith1988precise, sohi1990instruction, smith1991}. Enhanced architectural comparison Table 16.6 across all three landmark generations.
        \item \textit{Analytical Practice Problems with Worked Solutions}: Added Problems 16.5 (Pipeline Speedup and Imbalance Analysis), 16.6 (Forwarding Unit Hazard Equations and Priority), and 16.7 (Branch Predictor Performance and CPI Penalty) complete with step-by-step worked mathematical solutions.
    \end{itemize}
    \item \textbf{The RISC-V Processor: Architecture, Implementation, and Verification (Chapter 19)}: Authored and integrated Chapter 19 (\texttt{04\_19\_1\_RISCV.tex}) into Part IV (``Practical Designs'') of the textbook, alongside placeholder \texttt{04\_19\_2\_RISCV\_pipelined.tex}. Fully documented the RISC-V RV32I base integer ISA with the \texttt{Zmmul} multiplication extension, the Harvard 5-OS hardware composition and 5-function Fetch-Execute microarchitecture, and the complete cycle-accurate Chisel/Scala verification methodology using \texttt{EphemeralSimulator}. Documented 100\% pass verification results across all 42 official RISC-V architectural test suites (\texttt{riscv-arch-test}) with bit-exact signature matches against Spike golden reference models and refined test results table formatting to fit page boundaries cleanly. Streamlined Chapter 13 by replacing inline Chisel core listings with a concise reference to Chapter 19.
    \item \textbf{RISC-V 5-OS Harvard Fetch-Execute Processor (Chapter 13 \& Appendix A99)}: Designed and implemented a synthesizable single-cycle Fetch-Execute processor in Chisel (\texttt{RiscvFetchExecute.scala}) executing the RV32I\_Zmmul instruction set, along with a complete Harvard 5-OS computer system test harness (\texttt{RiscvSystem}). Aligned loop definitions strictly with Figure 13.3 (1-OS memory bit cell, 2-OS PC and RALU automata loops, 3-OS PC-RALU interaction loop, 4-OS Program Memory loop, and 5-OS Data Memory loop). Partitioned the processor cycle into five unified logical functions (Instruction Fetch, Instruction Decode \& Immediate Generation, Operand Fetch \& ALU Execution, Data Memory Access \& Register Write-Back, and Next-PC Generation), eliminating all pipeline hazards, wait states, and stall signals by coupling with unbuffered simulated memory. Directly reused library modules developed in prior chapters (\texttt{ProgramCounter}, \texttt{RiscvDecoder}, \texttt{RiscvImmGen}, \texttt{RiscvRegFile}, \texttt{RiscvALU}, and \texttt{RiscvDataMemory} as \texttt{byteMemory}).
