\chapter*{Changelog}
\addcontentsline{toc}{chapter}{Changelog}

This section summarizes notable changes to the textbook, code listings, and hardware testbenches since the release of the First Edition PDF (\texttt{Structured\_Computer\_Architecture\_1st\_edition\_2026\_06\_03.pdf}, June 3, 2026).

\begin{itemize}
    \item \textbf{Performance Optimized Organization: Pipelining and ILP (Chapter 16)}: Renamed chapter file to \texttt{04\_16\_Performance\_Optimized\_Organization.tex} and updated master inclusion in \texttt{Latex/00\_main.tex}. Enhanced chapter with rigorous pedagogical, analytical, and microarchitectural additions without disturbing existing content:
    \begin{itemize}
        \item \textit{Pedagogical Bridge \& Performance Metrics}: Added an introductory bridge connecting Chapter 15 gate-level optimizations to system-level organization and formalized the fundamental iron law of processor performance ($\text{Execution Time} = \text{IC} \times \text{CPI} \times T_{clock}$), pipeline CPI degradation, and speedup formulas.
        \item \textit{Barrel Multithreading Hazard Elimination}: Established how $N = 4$ round-robin interleaved barrel multithreading matching the $k = 4$ stage toyRISC pipeline structurally guarantees that no pipeline hazards can exist, avoiding hardware stalls and forwarding multiplexers.
        \item \textit{Structural Hazards \& Hardware Replication}: Added Section 16.3.1 analyzing structural resource contention and necessary hardware replication, from dedicated PC incrementers (+4) and Harvard memory ports in basic pipelines to multiple ALUs, AGUs, and multi-ported register files in superscalar processors.
        \item \textit{Forwarding Truth Table \& Priority Logic}: Added Table 16.3 and Boolean hazard expressions for ALU operand forwarding controls, formalizing the imperative priority rule when back-to-back instructions target the same destination register.
        \item \textit{1-Bit vs. 2-Bit Branch Prediction Trace}: Corrected 2-bit counter description to a four-state automaton and added step-by-step trace Table 16.5 comparing 1-bit vs. 2-bit predictors on a 4-iteration loop, analytically demonstrating the elimination of the loop re-entry misprediction penalty ($(N-1)/N$ vs $(N-2)/N$).
        \item \textit{Out-of-Order Execution (Scoreboard vs. Tomasulo)}: Expanded Section 16.5 with in-depth treatments of Seymour Cray's CDC 6600 centralized Scoreboard (4 stages, stalls on WAR/WAW) and Robert Tomasulo's IBM 360/91 algorithm (3 stages, distributed reservation stations, dynamic register renaming eliminating WAR/WAW, Common Data Bus broadcast), accompanied by architectural comparison Table 16.6.
        \item \textit{Analytical Practice Problems with Worked Solutions}: Added Problems 16.5 (Pipeline Speedup and Imbalance Analysis), 16.6 (Forwarding Unit Hazard Equations and Priority), and 16.7 (Branch Predictor Performance and CPI Penalty) complete with step-by-step worked mathematical solutions.
    \end{itemize}
    \item \textbf{The RISC-V Processor: Architecture, Implementation, and Verification (Chapter 18)}: Authored and integrated Chapter 18 (\texttt{04\_18\_1\_RISCV.tex}) into Part IV (``Practical Designs'') of the textbook, alongside placeholder \texttt{04\_18\_2\_RISCV\_pipelined.tex}. Fully documented the RISC-V RV32I base integer ISA with the \texttt{Zmmul} multiplication extension, the Harvard 5-OS hardware composition and 5-function Fetch-Execute microarchitecture, and the complete cycle-accurate Chisel/Scala verification methodology using \texttt{EphemeralSimulator}. Documented 100\% pass verification results across all 42 official RISC-V architectural test suites (\texttt{riscv-arch-test}) with bit-exact signature matches against Spike golden reference models and refined test results table formatting to fit page boundaries cleanly. Streamlined Chapter 13 by replacing inline Chisel core listings with a concise reference to Chapter 18.
    \item \textbf{RISC-V 5-OS Harvard Fetch-Execute Processor (Chapter 13 \& Appendix A99)}: Designed and implemented a synthesizable single-cycle Fetch-Execute processor in Chisel (\texttt{RiscvFetchExecute.scala}) executing the RV32I\_Zmmul instruction set, along with a complete Harvard 5-OS computer system test harness (\texttt{RiscvSystem}). Aligned loop definitions strictly with Figure 13.3 (1-OS memory bit cell, 2-OS PC and RALU automata loops, 3-OS PC-RALU interaction loop, 4-OS Program Memory loop, and 5-OS Data Memory loop). Partitioned the processor cycle into five unified logical functions (Instruction Fetch, Instruction Decode \& Immediate Generation, Operand Fetch \& ALU Execution, Data Memory Access \& Register Write-Back, and Next-PC Generation), eliminating all pipeline hazards, wait states, and stall signals by coupling with unbuffered simulated memory. Directly reused library modules developed in prior chapters (\texttt{ProgramCounter}, \texttt{RiscvDecoder}, \texttt{RiscvImmGen}, \texttt{RiscvRegFile}, \texttt{RiscvALU}, and \texttt{RiscvDataMemory} as \texttt{byteMemory}). Verified with 100\% test coverage in \texttt{RiscvFetchExecuteTest.scala} and documented with an in-depth code walkthrough in Section 13.7.
    \item \textbf{Uniform Object-Oriented Inheritance, Listing Alignment \& Trait Mixin Analysis (Chapters 8, 9, \& 10)}: Refactored leaf modules (\texttt{Mux4}, \texttt{DeMux16}, \texttt{BehavioralAdder4}, \texttt{BehavioralAdderSubtractor4}, and \texttt{BehavioralAdderSubtractorHW4}) to specialize their parameterized base classes via direct class inheritance (\textit{is-a} derivation) rather than boilerplate module wrapper encapsulation; aligned all code listing starting lines to their exact structural declarations (\texttt{RiscvDecoder} at L7, \texttt{BehavioralAdderSubtractor4} at L8, \texttt{MultifunctionAdderSubtractor} at L8, \texttt{RiscvALU} at L8, \texttt{SRAM} at L8, \texttt{PipelinedSRAM} at L9, \texttt{RiscvDataMemory} at L7, \texttt{RegFile2R1WVec} at L9, \texttt{RegFile2R1WSRAM} at L12, \texttt{RiscvRegFile} at L9, \texttt{LanguageRecognizer} at L7, \texttt{GCD} at L10, \texttt{ProgramCounter} at L7, and \texttt{RALU} at L9); refactored \texttt{ProgramCounter.scala} and \texttt{LanguageRecognizer.scala} to use one-hot state decoding and idiomatic \texttt{MuxCase} combinational logic (removing disallowed \texttt{switch} statements); eliminated page-split in Section 9.3.1 to guarantee a single contiguous page for \texttt{Register.scala}; stripped dead debug printing statements from \texttt{MultifunctionAdderSubtractor64} and \texttt{ALU64} with line widths constrained to $\le 65$ characters; and integrated an in-depth architectural analysis exploring Scala trait mixin composition, hardware duplication pitfalls (e.g. redundant arithmetic carry chains and comparators), and the necessity of empirical synthesis experimentation.
    \item \textbf{Modular RV32I\_Zmmul Architecture \& Datapath Elements (Chapters 8, 9, \& 10)}: Implemented modular synthesizable Chisel RTL modules for the RV32I base ISA with the Zmmul standard extension using object-oriented Scala abstractions, typed communication bundles (\texttt{DecodedInstruction}, \texttt{DecodedControl}), and named field accessors (\texttt{RiscvFields}). Features include a zero gate-delay instruction decoder (\texttt{RiscvDecoder.scala}) with direct-wire opcode routing ($\{\text{inst}[25], \text{inst}[30], \text{inst}[14:12]\}$), a dedicated multi-format immediate generator (\texttt{RiscvImmGen.scala}), a high-performance 32-bit ALU (\texttt{RiscvALU.scala}) implementing all 10 integer operations and 4 multiplication operations with condition flags, a byte-addressable synchronous data memory (\texttt{RiscvDataMemory.scala}) supporting byte/halfword/word access with sign/zero extension, an extended Program Counter (\texttt{ProgramCounter.scala}) providing link address output (\texttt{pcPlus4}), and an integrated execution engine (\texttt{RALU.scala}). All modules verified with 100\% test coverage across 29 test suites and formatted as contiguous single-page listings.
    \item \textbf{RISC-V Hardware Bridge \& Listing Layout Refinements (Chapters 9 \& 10)}: Integrated synthesizable Chisel RTL modules and test suites bridging 1-OS and 2-OS automata to the RISC-V ISA (\texttt{RiscvRegFile}, \texttt{LanguageRecognizer}, \texttt{ProgramCounter}, and \texttt{RALU}); refactored ALU logic to idiomatic \texttt{MuxCase} (removing disallowed \texttt{switch} statements); corrected pipelined SRAM code listing inclusion; resolved syntax highlighting quirks; eliminated code truncation across listings; and enforced unbroken, contiguous code listings across all Chapter 9 and 10 modules.
    \item \textbf{Comprehensive Subject Index and Glossary}: Expanded the textbook index into a unified Subject Index and Glossary with 490 categorized entries across all chapters and appendices, featuring hierarchical sub-entries, cross-references (\texttt{|see}), concise architectural definitions, historical biographies, custom alphabetical MakeIndex formatting (\texttt{index\_style.ist}), and cross-platform font compatibility.
    \item \textbf{Performance Optimized Digital Logic (Chapter 15)}: Unified high-performance adder architectures (CLA, CSA, Kogge-Stone) with analytical formulations and comparative trade-offs, converted inline code to \texttt{chiselcode}, integrated the combinational (\texttt{RegFile2R1WVec}) and multi-banked (\texttt{RegFile}) register file implementations, and reframed sequential automata around timing closure and critical path optimization.
    \item \textbf{Build Infrastructure \& Chisel/Scala Toolchain}: Upgraded Chisel hardware construction library to version 7.15.0 and Scala to version 2.13.18 in \texttt{RTL/Chisel/build.sbt}, and updated compiler plugins for CIRCT firtool 1.158.0.
    \item \textbf{RTL \& Simulation Testbenches}: Adapted testbenches for Chisel 7 simulation semantics (explicit reset pulse for \texttt{WaveFormGeneratorSpec} and deterministic thread isolation initialization in \texttt{RegFileMT2R1WSRAMTest}), achieving 100\% pass across all 20 unit test suites.
    \item \textbf{Generated Verilog Artifacts}: Re-emitted clean and annotated synthesizable SystemVerilog models (\texttt{GCD.sv} and \texttt{WaveFormGenerator.sv}) using the CIRCT firtool 1.158.0 backend.
    \item \textbf{Textbook Documentation \& Appendices}: Updated Chisel and Scala version references across Chapter 2 and Appendix A, updated Appendix A testing documentation to reflect Chisel's built-in \texttt{EphemeralSimulator}, and corrected build configuration code listing captions and directory references in the installation guide.
    \item \textbf{Front Matter \& Typography}: Integrated Overleaf typographical refinements in \texttt{Latex/00\_main.tex}, updated circuit drawing assets in \texttt{Latex/figures/DRAW0\_28.LP}, and aligned copyright and edition preface metadata.
\end{itemize}
